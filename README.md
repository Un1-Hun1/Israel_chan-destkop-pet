# 🇮🇱 Momo — Israel-chan desktop pet

Пиксельная аниме-девочка, которая живёт у тебя на рабочем столе Windows.
Гуляет по окнам, летает на ракете, спускается на парашюте и болтает на иврите и по-русски.

*A tiny pixel anime girl for your Windows desktop: walks on your windows, rides a rocket,
parachutes down and chats in Hebrew & Russian.*

## ⬇️ Скачать

**[Скачать MomoPet.exe](https://github.com/Un1-Hun1/Israel_chan-destkop-pet/releases/latest/download/MomoPet.exe)** — один файл, ничего устанавливать не нужно.

1. Скачай `MomoPet.exe` и положи в любую папку (например, `Документы\MomoPet`).
2. Запусти двойным кликом.
3. Если Windows покажет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**.
   Это обычное предупреждение для программ без платной цифровой подписи.

## ✨ Что она умеет

- 🚶 гуляет по панели задач и по верхним краям открытых окон
- 🪟 сидит на окнах и болтает ногами; двигаешь окно — она едет вместе с ним
- 🚀 примерно раз в 30 секунд летает по экрану на ракете
- 🪂 потом спрыгивает и плавно спускается на парашюте
- 💭 думает облачками: фразы на иврите (с переводом) и по-русски
- 🖱️ её можно схватить мышкой и бросить, погладить кликом, разбудить
- 😴 засыпает, если долго ничего не происходит
- 🎮 сама прячется, когда открыта игра или видео на весь экран

## 🎛️ Управление

- **Виджет** на рабочем столе — клик включает/выключает Момо, его можно перетащить.
- **Правый клик по виджету** — «Позвать сюда», размер, автозапуск с Windows, выход.
- **Правый клик по Момо** — погладить, «Скажи что-нибудь», «Полетать на ракете», спрятать.
- Повторный запуск `MomoPet.exe` тоже включает/выключает её.

## 💬 Свои фразы

Рядом с `MomoPet.exe` появится файл `phrases.txt` — открой его Блокнотом и допиши свои фразы.
Одна строка — одна фраза, `|` переносит на новую строку (удобно для перевода):

```
[hebrew]
מה נשמע? | Как дела?
```

Изменения подхватываются сразу, перезапускать не нужно.

## 🛠️ Запуск из исходников

Нужен Python 3.11+ и Pillow:

```
pip install pillow
pythonw pixelpet.pyw
```

Сборка `.exe`:

```
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --name MomoPet --icon icon.ico --add-data "phrases.txt;." pixelpet.pyw
```
